# EMAA MVP

نسخة أولية قابلة للتشغيل لمشروع EMAA: نظام وكلاء ذكي للتواصل التعليمي الفوري مع الطلاب الصم وذوي صعوبات النطق.

## التشغيل

للتشغيل الكامل مع نموذج الكلمات الخلفي:

```powershell
py -3 -m pip install -r requirements.txt
py -3 server.py
```

أو:

```powershell
python -m pip install -r requirements.txt
python server.py
```

أو:

```powershell
python server.py
```

ثم افتح التطبيق من نفس الخادم:

```text
http://127.0.0.1:8000
```

يفضل التشغيل عبر `localhost` أو `127.0.0.1` حتى تعمل صلاحيات الكاميرا في المتصفح، ويصل التطبيق مباشرة إلى واجهة التحليل الخلفية بدون تعارض منافذ.

إذا لم تكن مكتبات Python الخاصة بالتحليل مثبتة، يمكن تشغيل وضع المتصفح فقط عبر:

```powershell
node tools/static_server.js 4173
```

ثم افتح:

```text
http://127.0.0.1:4173
```

في هذا الوضع ستعمل قراءة الحروف وتدريب إشارات EMAA داخل المتصفح، بينما يبقى نموذج الكلمات الخلفي غير متاح حتى تثبيت اعتمادات Python.

## ما تحتويه النسخة

- واجهة الطالب: بدء جلسة، تشغيل الكاميرا، اختيار إشارة تعليمية، تحليل النية، تأكيد الرسالة، وتحويلها لصوت.
- واجهة المعلم أو الدعم: استقبال رسالة الطالب، تشغيلها صوتياً، كتابة أو تسجيل الرد، تحليل النبرة، واكتشاف المصطلحات الأكاديمية.
- لوحة المدير: مؤشرات النظام، المستخدمون، إدارة المصطلحات، وإدارة الإشارات المدعومة.
- نموذج EMAA محلي: تدريب عينات للإشارات التعليمية من الكاميرا ثم اختبارها داخل المتصفح.
- نموذج مدرب جاهز لحروف لغة الإشارة العربية تم استخراجه من `Arabic-Sign-Language-Recognition-main.zip`.
- تخزين محلي عبر `localStorage` لسجل الجلسات وإعدادات التدريب.

## النموذج الجاهز للحروف

هذا النموذج مبني على الملفين:

- `Arabic-Sign-Language-Recognition-main/sign_language_model.h5`
- `Arabic-Sign-Language-Recognition-main/classes.npy`

تم تحويل النموذج إلى ملف متصفح:

- `assets/arabic-sign-letters-model.json`

ويعمل على:

- 31 فئة من حروف لغة الإشارة العربية.
- 63 قيمة إدخال لكل عينة: `x,y,z` لعدد 21 landmark من MediaPipe Hands.
- شبكة كثيفة بالطبقات: `63 -> 256 -> 128 -> 64 -> 31`.

اختبار النموذج داخل المشروع على ملف البيانات المرفق:

- `7137` عينة
- دقة `98.18%`

## استخدام نموذج الحروف

1. شغل الكاميرا.
2. اضغط `تحميل النموذج الجاهز`.
3. اضغط `اختبار الحرف بالكاميرا`.
4. راقب الحرف المتوقع ونسبة الثقة والبدائل.
5. استخدم `إضافة الحرف` لتجميع كلمة من الحروف المتوقعة.

## استخدام نموذج EMAA المحلي

1. شغل الكاميرا.
2. اضغط `تحميل نموذج اليد`.
3. اختر الإشارة من القائمة.
4. احفظ 5 إلى 10 عينات للإشارة.
5. كرر التدريب مع إشارات أخرى.
6. اضغط `تدريب النموذج`.
7. اضغط `تحليل بالكاميرا`.

## ملاحظات تنفيذية

النموذج الجاهز الموجود في الملف المضغوط مدرب على حروف لغة الإشارة العربية، وليس على نوايا EMAA التعليمية مثل "أحتاج مساعدة" أو "موعد اختبار". لذلك أبقينا في التطبيق مسارين منفصلين:

- مسار حروف الإشارة العربية باستخدام النموذج الجاهز.
- مسار نوايا EMAA التعليمية باستخدام تدريب محلي داخل المتصفح.

الملفات الأساسية:

- `index.html`: هيكل التطبيق.
- `styles.css`: تصميم الواجهات والاستجابة للشاشات.
- `app.js`: منطق الجلسات، الوكلاء، التدريب، وتحليل الحروف.
- `assets/arabic-sign-letters-model.json`: النموذج الجاهز بعد تحويله من `H5`.
- `tools/export_asl_model.py`: محول `H5` إلى JSON.
- `tools/test_exported_asl_model.py`: اختبار دقة النموذج المحول على ملف البيانات.
